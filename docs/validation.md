# 検証方針

モデル分類型支援では、分類数や推薦順位を固定的な正解とは扱いません。

## 3層を分けて検証する

### 1. 課題分類
相談・観察情報から、教師が検討すべき2つの課題へ適切にたどり着けるかを確認します。

主な観点:
- 現在の48分類で現場の困りを十分に表せるか
- 似すぎた分類がないか
- 一つの分類に異なる指導が混在していないか
- 分類を分けることで実際の目標・手立てが変わるか

### 2. 指導プラン
分類が合っていても、指導プランが合っているとは限りません。

主な観点:
- 短期目標が観察可能か
- 学年に合う具体性か
- つまずきの観点に手立てが対応しているか
- 人的支援の量が適切か
- 本人の認識・希望が反映されているか
- 本人への訓練より環境調整が適切なケースを見落としていないか

### 3. 教材候補
教材の母体はNotion「使用教材」です。

主な観点:
- 課題に直接対応しているか
- 学年・認知言語・支援量に合うか
- 実際の個別指導時間で使用可能か
- なぜ推薦されたか説明できるか
- 実践後の評価から順位を見直せるか

「完成教材だから上位」ではなく、まず課題との直接対応を優先します。

## 基準ケース

`data/validation-cases.json` に架空ケースを蓄積します。

基準ケースは「唯一の正解」を示すものではありません。
分類・指導プラン・教材推薦の変更によって、以前妥当だった出力が不意に崩れていないかを比較するためのテストケースです。

最初のケースは `TEST-001 小2・注意集中＋衝動反応` です。

今後、同じ診断・学年でも異なる課題になるケースを増やします。これにより、診断名直結の推薦になっていないことも確認します。
