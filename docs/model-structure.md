# モデル構造

## 8つの大領域
1. 自己理解
2. 感情・自己調整
3. 注意・実行機能
4. 他者理解・社会認知
5. 対人関係・コミュニケーション
6. 援助要請
7. 学習への取り組み
8. 身体・感覚

## 5つの中核変数

### 1. 中心課題
何について学ぶのか。診断名ではなく、現在の自立活動上の中心課題を選ぶ。

### 2. 具体的困り感
場面、現れ方、影響、頻度を分ける。

### 3. つまずき段階
1. 知識
2. 気づき
3. 理解
4. 判断
5. 実行
6. 振り返り
7. 般化

### 4. 支援レベル
- Lv0 未経験・困難
- Lv1 全面支援
- Lv2 選択支援
- Lv3 手掛かり支援
- Lv4 自立
- Lv5 般化

### 5. 本人の認識・希望
本人が何に困り、どうなりたいかを確認する。周囲の都合だけで目標を設定しない。

## 質問分岐
基礎情報
→ 中心領域
→ 現れ方
→ つまずき段階
→ 支援レベル
→ 本人の認識
→ 主モデル＋関連モデル
→ 教材・評価
