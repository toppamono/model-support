# 設計思想

## 目的
このツールは、児童を分類するためではなく、特別支援教室における個別指導で「何を見立て、何を試し、どう評価するか」を整理するための仮説生成支援ツールです。

## なぜ分類を使うのか
学校現場では、限られた時間で支援方針を立てる必要があります。一方、診断名や表面行動だけで支援を決めると、同じ行動でも異なる背景を見落としやすくなります。

そこで、固定的な人物分類ではなく「現在の課題状態」をモデル化します。

## 基本構造
基礎情報 + 5つの中核変数
→ 主モデル + 関連モデル
→ 指導の大枠
→ 教材候補
→ 評価
→ 試行・再評価

## 重要な緊張関係
分類は判断を助けますが、分類そのものが児童理解を狭める危険もあります。そのため、本ツールは「答えを出す装置」ではなく「見落としを減らすチェック装置」として設計します。

特に、本人・学校・家庭の困り感が一致しない場合を重要な情報として扱います。周囲にとっての困りと、本人にとっての困りは同じとは限りません。
